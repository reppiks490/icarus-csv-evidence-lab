## Evidence-tier mismatch requiring a contract test

ARGUS defines `E0 = OHLC proxy`, `E1 = trade prints`, `E2 = trades + top-of-book`, `E3 = market-by-price depth`, and `E4 = market-by-order`. AION's `aion/contracts.py::EvidenceTier` defines `CANDLE_PROXY = 1`, `INFERRED_TRADE = 2`, `TRUE_TRADE = 3`, `TRUE_DEPTH = 4`. These are different taxonomies, not just an off-by-one shift. An ARGUS `E2` record must not become AION's `INFERRED_TRADE` merely because both carry the integer `2`. The future adapter needs explicit source capabilities and separate tests for trade, quote, depth, and queue claims; ambiguous tiers must abstain.
